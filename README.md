# 八字排盘宝

- 项目是什么：面向手机浏览器的个人八字排盘与案例研究网站，可添加到手机主屏幕。
- 解决的需求：按出生资料排盘，收藏案例并记录分析；目前案例保存在使用设备的浏览器中。
- 核心功能：公历、农历和四柱反推输入；传统排盘与分析；案例收藏、检索、批量导入和备份导出。
- 当前阶段：稳定现有排盘功能，优化案例列表；评估手机与电脑之间的案例同步。
- 运行说明：网站静态文件位于 `dist/`；浏览器打开已发布网站即可使用。案例操作的针对性检查可运行 `node tests/case-actions.test.cjs`。
- 已发布网站：https://bazi-study-atlas-20261018.acoolmans.chatgpt.site/
